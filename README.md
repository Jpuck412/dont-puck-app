# Don't Puck App

Describe it. Build it. Own it. Deploy it.

An AI application-development platform: describe an app in plain
English, get a real generated repository, edit/preview/repair it,
push to GitHub, deploy to Vercel. No credit system — bring a local
model or your own provider key.
